# Hacking Tools

A collection of Python-based cybersecurity tools, scripts, and experimental projects developed for learning, exploring, and understanding various aspects of cybersecurity and ethical hacking.

This repository serves as my personal cybersecurity development lab, where I build and experiment with tools related to web application security, network reconnaissance, penetration testing, and security automation.

## About

The primary focus of this repository is developing practical cybersecurity tools while improving my Python programming, scripting, and penetration testing skills.

Projects range from simple automation scripts to more advanced security utilities, with an emphasis on understanding how security tools work and implementing their underlying concepts.

## Areas of Focus

- **Web Application Security:** HTTP endpoint discovery, directory enumeration, and web security testing.
- **Network Reconnaissance:** Network information gathering and scanning utilities.
- **Penetration Testing:** Exploring penetration testing methodologies and security assessment tools.
- **Security Automation:** Python scripts for automating repetitive security-related tasks.
- **Malware Analysis & Research:** Learning about payload generation and security testing in controlled lab environments.
