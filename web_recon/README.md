
# Web Reconnaissance

This directory contains reports and documentation from my web reconnaissance practice and experiments.

The reports cover different aspects of web reconnaissance, including HTTP analysis, directory enumeration, web server information gathering, and identifying potential security misconfigurations.

Most of these exercises are performed using my own Python tools and authorized lab environments.

## Repository Structure

```text
web_recon/
│
├── README.md
│
└── reports/
    ├── HTTP_Directory_Enumeration/
    └── ...
```

## Reports

Each report documents an individual practical exercise and may include:

- Objective and methodology
- Tools and technologies used
- Observations and findings
- Screenshots and supporting evidence
- Limitations and learning outcomes

## Purpose

This is part of my journey into cybersecurity and ethical hacking. The goal is to gain practical experience with web reconnaissance, understand how web applications and servers behave, and document what I learn along the way.

**Disclaimer:** All testing is intended for educational purposes and is conducted only on systems I own or have explicit permission to test.
